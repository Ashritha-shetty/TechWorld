# 💻 TechWorld - Electronics & Gadgets

TechWorld is a responsive e-commerce website designed for browsing and purchasing electronics and gadgets. The website provides a simple and user-friendly shopping experience with product categories, search, cart, wishlist, checkout, and order tracking features.

## 🚀 Features

* 🏠 Home page
* 📱 Smartphones category
* 💻 Laptops category
* 🎧 Audio products
* ⌚ Wearables
* 🔌 Accessories
* 🔍 Product search
* 🛍️ Product listing and filtering
* ❤️ Wishlist
* 🛒 Shopping cart
* 💳 Checkout page
* 👤 Account section
* 🏷️ Deals section
* 🚚 Order tracking
* 📞 Contact page
* ℹ️ About page
* 📱 Responsive design for desktop and mobile devices

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome

## 📂 Project Structure

```text
TechWorld/
│

```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the `TechWorld` folder.
3. Open `index.html` in a web browser.
4. Explore the website and test the features.

## 🎯 Project Objective

The objective of this project is to create a modern and responsive electronics e-commerce website that demonstrates front-end web development skills, including HTML structure, CSS styling, JavaScript functionality, product filtering, cart management, wishlist management, checkout, and order tracking.
